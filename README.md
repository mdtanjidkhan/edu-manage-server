# EduManage Server

REST API backend for **EduManage**, a full-stack School Management System built with Express.js and MongoDB.

## Key Features

* Role-based authentication & authorization
* Student and teacher management
* Attendance and marks APIs
* Class routine management
* Fee management
* Notice management
* Admission application APIs
* RESTful API architecture

## Tech Stack

**Node.js · Express.js · MongoDB · Better Auth · JWT · REST API · Vercel**

## AI Assistance

**Gemini & ChatGPT** — used as development assistants for debugging, problem-solving, code review, and exploring implementation approaches.

## Architecture

**Client → Express.js REST API → MongoDB**
